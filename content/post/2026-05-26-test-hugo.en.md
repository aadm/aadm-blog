## details

for example if you want to hide something now:

{{< details "Click to expand this section" >}}

{{< /details >}}

### columns

The `columns` and `column` shortcodes create a two-column layout:

{{< columns >}}
Left column content here.
{{< column >}}
Right column content here.
{{< /columns >}}
